# HimalayaAir

HimalayaAir is a Kathmandu Valley air-quality intelligence platform. It is designed to combine observed sensor data, modeled atmospheric fallback data, replayable demo data, time-series/geospatial storage, streaming processing, orchestration, forecasting, and a dashboard that clearly exposes data provenance.

The project prioritizes honest source labeling: observed, modeled, replay, and synthetic data must remain distinguishable throughout the pipeline.
